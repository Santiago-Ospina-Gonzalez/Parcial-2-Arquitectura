# Microservice de Pacientes

Microservicio Spring Boot con Clean Architecture y almacenamiento en memoria.
Se ejecuta en `http://localhost:3002`.

```powershell
mvn spring-boot:run
```

Endpoints:

- `GET /api/pacientes`
- `GET /api/pacientes/{id}`
- `POST /api/pacientes`
- OpenAPI: `/api/docs`
- Swagger UI: `/api/docs-ui`
