# Microfrontend de Citas

Remote Angular en `http://localhost:4203`. Consume
`Microservice-Citas-NodeJS` en el puerto `3003`.

Casos de uso: listar citas, consultar cita por ID y agendar cita.
La página expuesta por Module Federation es `AppointmentsPage`.

```powershell
npm install
npm start
npm run test:coverage
```
