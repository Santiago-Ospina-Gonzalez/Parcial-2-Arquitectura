# Microfrontend de Médicos

Remote Angular en `http://localhost:4201`. Consume
`Microservice-Medicos-NodeJS` en el puerto `3001`.

Casos de uso: listar médicos, consultar médico por ID y registrar médico.
La página expuesta por Module Federation es `DoctorsPage`.

```powershell
npm install
npm start
npm run test:coverage
```
