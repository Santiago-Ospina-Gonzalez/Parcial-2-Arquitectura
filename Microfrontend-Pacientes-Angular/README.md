# Microfrontend de Pacientes

Remote Angular en `http://localhost:4202`. Consume
`Microservice-Pacientes-SpringBoot` en el puerto `3002`.

Casos de uso: listar pacientes, consultar paciente por ID y registrar paciente.
El caso de uso de listado se usa en la página expuesta `PatientsPage`.

```powershell
npm install
npm start
npm run test:coverage
```
